# Todo-менеджер с файлом

```markdown
# Todo-менеджер
```

Консольная программа для управления списком задач с сохранением в файл `todos.txt`.

## 📦 Возможности

- ✅ `list` — показать все задачи с номерами
- ✅ `add Текст` — добавить новую задачу
- ✅ `done N` — удалить задачу под номером N
- ✅ `clear` — удалить все задачи
- ✅ `exit` — выход (автосохранение)

##  Как запустить

```bash
python todo_manager.py
```
## Пример вывода
```
Добро пожаловать в Todo-менеджер!

> list
Список задач пуст.

> add Купить молоко
Добавлено: Купить молоко

> add Позвонить маме
Добавлено: Позвонить маме

> list
1. Купить молоко
2. Позвонить маме

> done 1
Удалено: Купить молоко

> list
1. Позвонить маме

> exit
Сохранено. До свидания!
```
